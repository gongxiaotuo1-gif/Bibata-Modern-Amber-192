## Modifications

This repository adds a native 192px Linux XCursor build of
Bibata Modern Amber.

Changes include:

- Native 192px XCursor generation
- Dedicated `build-192.sh` build script
- Linux installation documentation
- Ubuntu 22.04 testing

The original cursor artwork and source assets originate from
the Bibata Cursor project.
