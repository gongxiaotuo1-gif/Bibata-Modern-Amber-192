
# Bibata Modern Amber 192

A native **192px XCursor variant of Bibata Modern Amber** for Linux.

This project is based on
[Bibata Cursor](https://github.com/ful1e5/Bibata_Cursor)
by **Abdulkaiz Khatri (ful1e5)**.

## About

The official Bibata XCursor release provides cursor sizes up to 96px.

This project adds a native **192px** build of **Bibata Modern Amber**
for users who prefer a much larger mouse cursor, especially on
high-resolution displays.

The 192px cursor is rebuilt from the original Bibata source assets
instead of simply scaling the official 96px cursor package.

## Features

- Native 192px Linux XCursor
- Bibata Modern rounded design
- Amber base color: `#FF8300`
- White outline: `#FFFFFF`
- Watch background: `#001524`
- Linux X11 / Wayland
- Tested on Ubuntu 22.04

- Python 3
- Node.js
- npm
